# Alien discovery model

An open forecast from [Event Neutral](https://eventneutral.com): will U.S. officials announce that extraterrestrial life exists? Built around Kalshi's `KXALIENS` markets.

- `index.html` and its subfolders: the site pages (served at alien-discovery-model.eventneutral.com). Question, Rules, Where things stand (Search for life, Government disclosure, and their pages), Model.
- `code/forecast_curve.py`: the forecast model. Edit the parameters block and run it to redraw the chart and write a month-by-month CSV.
- `model/explore/`: an interactive version of the same model in the browser (draft, not linked from the site yet). `model.js` is a line-for-line port of the Python.
- `assets/`: styles and charts.

Started 2026-11-05. Nothing here is financial advice.
